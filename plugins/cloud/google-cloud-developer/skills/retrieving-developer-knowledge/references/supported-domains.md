# 支持的开发者领域

Developer Knowledge API 和 MCP 服务器会从以下领域的官方公开页面中搜索、检索并综合文档内容：

<!-- LINT.IfChange -->

*   **Google Cloud 与基础设施**：
    *   `docs.cloud.google.com`（Google Cloud 官方文档）
    *   `cloud.google.com`（Google Cloud 解决方案与产品）
    *   `docs.apigee.com`（Apigee API 管理）
    *   `firebase.google.com`（Firebase 平台）

*   **AI 与机器学习**：
    *   `ai.google.dev`（Google AI 开发者平台与 Gemini API）
    *   `adk.dev`（Agent Development Kit）
    *   `antigravity.google`（Project Antigravity / Gemini CLI）
    *   `geminicli.com`（Gemini CLI 文档）
    *   `www.tensorflow.org`（TensorFlow 框架）

*   **移动、Web 与客户端平台**：
    *   `developer.android.com`（Android 开发者文档）
    *   `docs.flutter.dev`（Flutter 框架）
    *   `dart.dev`（Dart 语言）
    *   `developer.chrome.com`（Chrome 与 Web 扩展）
    *   `web.dev`（现代 Web 最佳实践）

*   **语言、工具与生态系统**：
    *   `go.dev`（Go 编程语言）
    *   `developers.google.com`（Google 开发者技术）
    *   `developers.home.google.com`（Google Home 开发者中心）
    *   `mapsplatform.google.com`（Google Maps Platform）
    *   `fuchsia.dev`（Fuchsia OS）

<!-- LINT.ThenChange(//depot/google3/third_party/devsite/developers/en/knowledge/reference/corpus-reference.md) -->

这些领域构成了可搜索、可检索技术内容的完整语料库。有关实时语料库的更多详情，请参阅[语料库参考](https://developers.google.com/knowledge/reference/corpus-reference)。
