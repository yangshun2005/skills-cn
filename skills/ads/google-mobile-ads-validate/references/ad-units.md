# 项目中无测试广告单元，格式正确

-   **按以下步骤操作**：
    -   [ ] 在代码库中搜索测试广告单元 ID：
        -   **AdMob**：任何以 `ca-app-pub-3940256099942544/` 开头的广告单元 ID。
        -   **Ad Manager**：任何以 `/6499/` 或 `/21775744923/` 开头的广告单元 ID。
-   **通过/失败标准**：
    -   **失败**：
        -   任何广告单元 ID 格式错误：
            -   **AdMob**：不匹配正则 `^(ca-app-pub-[a-zA-Z0-9\-]+)/([a-zA-Z0-9_\-]+)(/.*)?$`。
            -   **Ad Manager**：不匹配正则 `^/[0-9]*/.*|^/[0-9]*,[0-9]*/.*`。
    -   **警告**：
        -   在源文件中发现任何测试广告单元 ID，即使被 `DEBUG` 标志控制。
